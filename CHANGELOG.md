# Changelog

## 0.1.1

### Changed
- On Shopclass 7.1 the missing-key warning goes to the admin bell; older cores keep the banner.

## 0.1.0

### New
- Address lookup through the Google Geocoding API for listings with a street address.
- A separate server API key, never shown again after saving.
- Answers are kept 30 days, the longest Google allows.
- Translation template in `languages/google-geocoder.pot`.
